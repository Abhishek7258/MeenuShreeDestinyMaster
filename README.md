## ✨ Project
The repository is structured as a frontend web application with source code in `src/`, static assets in `public/`, and Vite handling the development/build workflow.

## 🚀 Run Locally
```bash
git clone https://github.com/Abhishek7258/MeenuShreeDestinyMaster.git
cd MeenuShreeDestinyMaster
npm install
npm run dev
```

See `package.json` for the authoritative scripts.
